# Write plainly

Use this skill to make writing clear, easy to find, easy to understand, and easy to act on.

## Choose the guides

Read [`guides/iso-24495-1/GUIDE.md`](guides/iso-24495-1/GUIDE.md) before producing any user-facing response or document. It sets the core plain-language rules.

Then read every guide that applies to the task:

- **Legal content:** Read [`guides/iso-24495-2/GUIDE.md`](guides/iso-24495-2/GUIDE.md) when drafting or reviewing contracts, licences, policies, terms, privacy notices, regulatory text, or other legal and compliance writing.
- **Technical content:** Read [`guides/iso-24495-3/GUIDE.md`](guides/iso-24495-3/GUIDE.md) when writing technical documentation, architecture material, technical analysis, scientific content, or code reviews.
- **Organisation-wide work:** Read [`guides/iso-24495-4/GUIDE.md`](guides/iso-24495-4/GUIDE.md) for plain-language gap analysis, maturity assessment, policy drafting, training plans, review workflows, or readiness work. This provisional guide requires the user's confirmation before a script reads a directory.
- **Document design:** Read [`guides/iso-24495-5/GUIDE.md`](guides/iso-24495-5/GUIDE.md) when structuring a long or complex report, specification, guide, contract, or other multi-section document. Read its required template before creating an ADR, runbook, or design document.
- **Source code:** Read [`guides/iso-24495-code/GUIDE.md`](guides/iso-24495-code/GUIDE.md) when writing or restructuring source code. It covers code order, names, comments, and error messages.
- **Text audit:** Read [`guides/iso-24495-text-audit/GUIDE.md`](guides/iso-24495-text-audit/GUIDE.md) only when the user explicitly asks to audit a selected Markdown or text path. The guide names the audit command and its scope limits.

## Apply the guidance

Use the core guide with each relevant specialist guide. Preserve technical, legal, and factual accuracy when it conflicts with a writing rule.

Follow the selected guide's workflow before using its scripts, templates, assets, or reference files. Treat the provisional organisation and document-design guides as guidance, not proof of ISO compliance.
